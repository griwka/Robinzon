# Дизайн-документ — «Затерянный остров»

## Идея
Уютная выживалка без стресса. Игрок оказался на тропическом острове: собирает ресурсы, мастерит,
строит лагерь, а затем на плоту открывает новые острова со своей темой. Ощущение — как в детской мобильной
«островной» игре, но в 3D, с прямым управлением персонажем и мультяшным low-poly стилем.

## Визуальный стиль (смесь двух источников)
| Из классической 2D-островной игры | Из современного стилизованного 3D (PEAK) |
|---|---|
| Сочная тёплая палитра: бирюза, жёлтый песок, яркая зелень | Low-poly геометрия, плоские грани |
| Чиби-пропорции персонажей, рыжие/русые растрёпанные волосы, рваная одежда | Toon-освещение с жёсткой границей тени |
| Бамбуковые хижины, факелы, деревянный UI с зелёными кнопками | «Резиновая» физичная анимация, мягкий туман и дымка вдали |
| Множество тематических островов | Вертикальность: гора-вершина, вид с высоты |

Правило: **не используем чужой арт, названия, музыку и персонажей**. Только свои модели и свои названия.

## Основной цикл
1. Собрать (кусты, пальмы, пляж) → 2. Скрафтить инструмент → 3. Добыть ресурс лучше →
4. Построить → 5. Выполнить задание → 6. Открыть новое.

Энергия ограничивает темп (1 за действие, восстановление со временем, еда, сон) — как в оригинальных
мобильных играх, но мягче: игру нельзя «застрять», энергия всегда восстанавливается сама.

## Ресурсы и инструменты (v0.1)
| Ресурс | Где | Нужно |
|---|---|---|
| Волокно | кусты | — |
| Камень | камешки на пляже / валуны | — / кирка |
| Древесина | плавник / пальмы | — / каменный топор |
| Пальмовый лист, кокос | трясти пальму | — |
| Ракушка | пляж | — |

## Острова (план, свои названия и темы)
| Остров | Тема | Новые механики |
|---|---|---|
| Стартовый | тропики | основы: сбор, крафт, стройка |
| Остров Великого Баньяна | гигантское дерево | лазание вверх (в духе PEAK), птичьи гнёзда |
| Старая крепость | руины, пушки | сундуки с замками, ключи, пещера |
| Грозовой | шторм, молнии | громоотвод, сбор энергии гроз |
| Ледяной | снег, пингвины | холод (нужен костёр/одежда), ледяные ларцы |
| Вулкан | лава, обсидиан | кузница, жар |
| Туманный | ночь, светлячки | фонари, тайны |

## Дорожная карта
- **v0.1 (сейчас)** — один остров, сбор/крафт/стройка, день/ночь, задания, сохранения.
- **v0.2** — свои модели из Blender (персонаж с ригом и анимациями), звуки и музыка, меню.
- **v0.3** — плавание на плоту, второй остров, лазание по скалам и деревьям.
- **v0.4** — ферма: грядки, животные (курица, коза), урожай со временем.
- **v0.5** — коллекции (бабочки сачком, ракушки), декор, кастомизация персонажа.
- **v0.6** — кооператив 2–4 игрока (Godot High-Level Multiplayer / Steam), посещение островов друзей.
- **v1.0** — 5+ островов, Steam-страница.

## Технические решения
- **Godot 4.5**, GDScript, рендерер Forward+ (на слабых ПК — Compatibility).
- Весь баланс — в `scripts/game.gd` (позже вынесем в JSON/ресурсы).
- Модели сейчас процедурные (`scripts/models.gd`); каждую функцию можно заменить загрузкой `.glb` из Blender.
- Высота рельефа считается функцией `Island.height_at()`, ею же пользуются строительство и шейдер воды.
